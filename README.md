# NiHao - Учим китайский с ИИ

Веб-приложение для изучения китайского языка с использованием инструментов машинного обучения. Проект реализует 4 ML-задачи: перевод текста, распознавание речи, детекция объектов на изображениях и видео.

## Описание проекта

NiHao — это образовательная платформа, которая помогает пользователям изучать китайский язык с помощью современных моделей машинного обучения. Приложение предоставляет инструменты для:

- перевода текста между английским и китайским языками;
- распознавания китайской речи из аудиофайлов;
- детекции объектов на фотографиях с китайскими подписями;
- детекции объектов в видео с формированием словаря китайских слов.

## Технические задания

### 1. Работа с текстом: машинный перевод EN ⇄ ZH

**Техническое задание:** создать двунаправленный переводчик текста между английским и китайским языками с использованием готовых моделей машинного обучения.

**Реализация:**
- модели: `Helsinki-NLP/opus-mt-en-zh` (EN→ZH) и `Helsinki-NLP/opus-mt-zh-en` (ZH→EN);
- библиотека: Hugging Face Transformers;
- функциональность: переключатель направления перевода, поддержка текстов до 1000 символов, проверка соответствия языка выбранному направлению.

### 2. Обработка аудио: Speech-to-Text для китайского

**Техническое задание:** разработать систему распознавания китайской речи из аудиофайлов с сегментацией текста.

**Реализация:**
- модель: `openai/whisper-small`;
- библиотека: Hugging Face Transformers;
- функциональность: поддержка форматов `.wav`, `.mp3`, `.flac`, `.ogg`, `.m4a`; сегментация текста по временным меткам через `return_timestamps=True`.

### 3. Обработка изображений: детекция объектов с китайскими подписями

**Техническое задание:** создать систему детекции объектов на изображениях с переводом названий на китайский язык.

**Реализация:**
- модель: YOLOv8n (nano-версия);
- библиотека: Ultralytics (PyTorch);
- датасет: COCO (80 классов объектов);
- функциональность: автоматическая разметка изображений, перевод названий объектов на китайский через словарь `COCO_ZH`, визуализация результатов через Pillow.

### 4. Обработка видео: детекция объектов в видео

**Техническое задание:** разработать систему анализа видео с детекцией объектов и созданием словаря китайских слов.

**Реализация:**
- модель: YOLOv8n (та же, что в задаче 3 — переиспользуется);
- библиотеки: Ultralytics (PyTorch) + OpenCV;
- функциональность: обработка по 1 кадру в секунду, сбор сводной статистики по объектам, сохранение размеченных ключевых кадров.

## API и тесты

### FastAPI-сервис перевода

| Метод | URL | Назначение |
|---|---|---|
| GET | `/` | Проверка работоспособности (health check) |
| POST | `/translate` | Перевод; тело запроса JSON с полями `text` и `direction` |
| GET | `/translate` | Перевод через query-параметры (для проверки в браузере) |
| GET | `/docs`, `/redoc` | Автоматическая документация OpenAPI |

**Валидация (Pydantic):** `text` — строка от 1 до 1000 символов; `direction` — только `en_to_zh` или `zh_to_en` (тип `Literal`); дополнительно проверяется соответствие языка текста выбранному направлению (для EN→ZH — не менее 60% английских букв, для ZH→EN — не более 50%).

**Коды ошибок:**
- 422 — не прошла валидация Pydantic;
- 400 — текст не соответствует выбранному направлению;
- 500 — сбой модели.

### Тесты

39 тестов на pytest, объединённых в 6 классов:

| Класс | Кол-во | Что проверяет |
|---|---|---|
| TestLanguageDetection | 13 | Функции `detect_english_ratio` и `validate_language` |
| TestHealthCheck | 1 | Доступность сервиса |
| TestTranslationPOST | 11 | Успешный перевод, ошибки валидации, неверный язык |
| TestTranslationGET | 7 | Те же сценарии через query-параметры |
| TestEdgeCases | 4 | Граничные длины текста, спецсимволы, Unicode |
| TestAPISpecification | 3 | Доступность OpenAPI, Swagger UI, ReDoc |
| **Итого** | **39** | |

Модель подменяется через `@patch('ml_text.api_views.translate')` — тесты выполняются за несколько секунд без загрузки весов.

### CI

GitHub Actions запускает тесты при каждом push и pull request (`.github/workflows/tests.yml`). Используется Python 3.12, зависимости ставятся из `requirements-api.txt` (минимальный набор для API и тестов).

## Установка и запуск

### Требования

- Python 3.12
- pip
- виртуальное окружение

### Установка зависимостей

```bash
python3 -m venv venv
source venv/bin/activate  # для Linux/macOS
pip install -r requirements.txt
```

### Запуск Django-проекта

```bash
cd NiHao
python manage.py migrate
python manage.py runserver
```

Приложение доступно по адресу: http://127.0.0.1:8000/

### Запуск FastAPI-сервера

```bash
cd NiHao
python -m uvicorn ml_text.api_views:app --reload --host 0.0.0.0 --port 8001
```

Документация API: http://127.0.0.1:8001/docs

> Django и FastAPI запускаются на разных портах (8000 и 8001), чтобы избежать конфликта.

### Запуск тестов

```bash
cd NiHao
python -m pytest ml_text/tests/test_api.py -v
```

## Преимущества выбранных библиотек

### Hugging Face Transformers

- **Преимущества:** широкая экосистема предобученных моделей, единый API для разных типов задач (NLP, ASR), локальный запуск без оплаты
- **Выбор:** наиболее распространённое решение для задач обработки естественного языка; подробная документация, активное сообщество

### Ultralytics YOLOv8

- **Преимущества:** высокая скорость детекции, поддержка PyTorch, доступны разные размеры модели (n/s/m/l/x)
- **Выбор:** высокое соотношение скорости и точности, простая интеграция через библиотеку Ultralytics

### OpenCV

- **Преимущества:** стандарт для обработки видео, богатый функционал, кроссплатформенность
- **Выбор:** надёжность, скорость, обширная документация

## Принцип работы моделей

### Helsinki-NLP/opus-mt-*

- **Архитектура:** sequence-to-sequence модель на основе Transformer
- **Принцип:** кодировщик преобразует входной текст в векторное представление, декодировщик генерирует перевод по токенам (cross-attention, beam search)
- **Выбор:** компактные модели, работающие на CPU без GPU; покрытие пары EN ⇄ ZH

### Whisper Small

- **Архитектура:** transformer-based модель для speech-to-text
- **Принцип:** энд-энд модель, преобразующая аудио напрямую в текст с учётом языка
- **Выбор:** высокое качество распознавания многоязычной речи, поддержка сегментации

### YOLOv8n

- **Архитектура:** CNN-based детектор объектов с архитектурой CSPDarknet
- **Принцип:** single-stage детекция, предсказывает bounding boxes и классы за один проход
- **Выбор:** баланс между скоростью и точностью, лёгкая версия для работы на CPU

## Структура датасетов

### COCO Dataset (для YOLOv8)

- **Размер:** ~330 тыс. изображений, 80 категорий объектов
- **Структура:** каждое изображение размечено bounding boxes с категориями
- **Использование:** предобученная модель YOLOv8n обучена на этом датасете
- **Классы:** person, car, dog, cat и др. (80 классов)

### Датасеты для Whisper

- **Размер:** ~680 тыс. часов аудио на 99 языках
- **Структура:** аудиофайлы с текстовыми транскрипциями
- **Использование:** предобученная модель Whisper обучена на многоязычных данных

## Метрики качества моделей

| Модель | Метрика | Значение | Время обработки |
|---|---|---|---|
| Helsinki-NLP/opus-mt-* | BLEU | ~28–32 для EN–ZH | ~50–100 мс на предложение (CPU) |
| Whisper Small | WER | ~1–3% (англ.), ~5–10% (кит.) | ~1–2 с на 10 с аудио (CPU) |
| YOLOv8n | mAP@50 | ~0,53 на COCO val | ~10–20 мс на изображение 640×640 (CPU) |

*Метрики приведены по данным авторов моделей; собственное качество оценивалось на подготовленных примерах и по времени работы.*

## Особенности реализации

### Кеширование моделей

- Все модели загружаются один раз при первом запросе (ленивая инициализация)
- Глобальные переменные для хранения загруженных моделей
- Значительное ускорение последующих запросов

### Обработка файлов

- Временное сохранение загруженных файлов в `MEDIA_ROOT`
- Автоматическое удаление временных файлов после обработки
- Валидация форматов и размеров файлов

### Структурирование результатов

- Распознанный текст разбивается на сегменты через `return_timestamps=True`; каждый сегмент выводится с новой строки
- Пунктуация внутри сегментов определяется моделью Whisper — для китайского она ставится не всегда
- На изображениях и кадрах видео подписи объектов рисуются через Pillow (рамки + китайские названия)

### Пользовательский интерфейс

- Единый дизайн в китайском стиле
- Интуитивно понятные формы
